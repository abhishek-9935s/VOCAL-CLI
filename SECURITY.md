# Security

VocalCLI proposes shell commands but is **not a sandbox**. Its safety filters are best-effort heuristics and are not a guarantee that a command is safe. Review commands and run with the minimum necessary permissions. See the README for privacy and data-sharing details.

## Reporting a vulnerability

Please do not publish exploit details or real credentials in an issue. If private vulnerability reporting is enabled in the repository's **Security** tab, use it to report the issue to the maintainers. Otherwise contact a repository maintainer privately and ask for a secure reporting channel before sending sensitive details. Include reproduction steps, the affected version, operating system and shell, and a description of the impact; redact secrets and personal data.
